# Upload manifest for `github.com/hanxiaole666/counting-laws`

Everything in this file is a decision about *what goes in the public repository*,
sized from the working tree as it stands. Two rules govern it:

1. **No third-party data.** Neither raw dataset is redistributed. Both are fetched
   by `experiments/data_io.py`, which verifies sha256 and resumes partial
   downloads.
2. **The paper's numbers must be recomputable from the upload alone.** So the
   result files that `paper_aij/build_assets.py` reads *are* included; nothing is
   summarised or cherry-picked.

## Order of operations

```bash
# 1) make a clean tree with only Tier 1
git init counting-laws && cd counting-laws
#   copy the Tier-1 paths in, then:
git add -A && git commit -m "counting laws: code, artefact, manuscript source"

# 2) prove the upload is self-contained before pushing
python tools/countlaws.py --n 4096 --w 64 --g 96 --s 4        # 358,906
python -m pytest tests -q                                     # 76 passed
python paper_aij/build_assets.py                              # 277 macros, 7 tables
python paper_aij/check_numbers.py                             # PASS (51 macros)
python tools/trace.py --check                                 # PASS (277 traced)
python tools/refresh_readme.py --check                        # README blocks current
cd paper_aij && pdflatex main && bibtex main && pdflatex main && pdflatex main

# 3) release the Tier-2 artefacts, then set the repo URL in the paper
#    (main.tex, Data availability) and re-run step 2 once more.
```

A referee will do steps 2 and 3 in the opposite order — start from the URL in the
paper. If the URL does not resolve, or `main.pdf` does not rebuild, the artefact
fails regardless of what the numbers say.

## Naming

`counting-laws` is the recommendation: it names the contribution (two exact
counting laws), it is not a method name that a later paper would have to
disambiguate, it is short enough to type in a footnote, and it is honest — the
repository is the laws plus the evidence that they hold and the evidence that
three of the authors' own claims did not.

Alternatives considered and rejected: `pswa-bench` (names one pattern, and the
paper's point is that the pattern name is the wrong unit), `supervision-bound`
(names half the paper), `veri-finrisk` (inherits the earlier system name that the
paper now partly refutes).

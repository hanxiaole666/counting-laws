## Checking a single number

The fastest way to audit one claim is to ask this tool about the macro
that carries it, then open the file it names at the path it prints.

```bash
python tools/trace.py --macro VramTimesSdpa
python -c "import json;print(json.load(open('results/run_20261116_094330/s1_pswa/gpu_memory_latency.json'))['bench']['rows'][-1]['modes']['pswa'])"
```

A macro whose value disagrees with the file it names is a build error,
not a judgement call: `check_numbers.py` re-derives every audited macro
through a second, independent code path and fails when the two differ.
